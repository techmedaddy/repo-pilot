# Prompt 006 — User Interface

## Prompt
Design an engineer-grade dashboard for RepoPilot featuring chat, live workflow execution steps, structured evidence-based reports, comparison mode, and human-in-the-loop approvals.

## Generated Approach
- Developer-friendly high contrast dark/light interface with clean typography (Plus Jakarta Sans + Fira Code).
- Real-time step progress indicator with time elapsed and status icons.
- Deep architectural report tabs: Overview & Stack, Component Flow, Reliability & Scale, Security & Vulnerabilities, Actionable Recommendations.
- Human-in-the-Loop interactive checklist approval mechanism.
- Repository comparison matrix.
